Your data

What this client keeps about you, where it lives, and how to take it with you or erase it.

Where it lives

Cookies live in this browser. The browser sends them to this client server with every request, and the server reads them to build your pages. Files live on this client server, in a folder named after your profile ID. None of this is sent to providers, to the network or to advertisers. It is not an account and it does not sync between browsers.

In this browser

  • Appearance, accent, text size and motion
  • Content filters
  • Likes and dislikes
  • Home feed order
  • Keyboard shortcuts and the getting started panel

On this server

  • Follows, saved posts and mutes
  • Names you gave to keys and your own display name
  • Media origins, network choices and confirmed warnings
  • Report receipts and provider manifests you have seen
  • Your identity entries and publishing journal
