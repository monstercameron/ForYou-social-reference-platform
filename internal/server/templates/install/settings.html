Install ForYou

Installing adds ForYou to your home screen or app list and opens it in its own window. It is the same site served by this server: your settings and your key stay where they are now, on this server for this browser.

Your browser keeps a copy of the styles, scripts, icons and one offline page, so ForYou can tell you when you are offline. It does not keep posts, replies, your settings or anything about what you read. Installing sends nothing to the network.

You are using the installed app.

How to install

  • Chrome or Edge on a computer: choose Install in the address bar, or Install ForYou in the browser menu.
  • Android: open the browser menu and choose Install app or Add to Home screen.
  • iPhone and iPad: in Safari, tap Share, then Add to Home Screen.
  • If your browser shows no install option, ForYou works the same in a tab.

Browsers offer installing only over HTTPS or from this computer's own address (localhost). To remove the app, uninstall it like any other app. To delete the saved copy, clear this site's data in your browser settings.
